# BNX Mail - Complete API Documentation
> Comprehensive API specification for **Storage, Subscription, Mail Backup (Vault), Settings, and Account Management**.

---

## 📌 Global Specifications
- **Base URL:** `http://localhost:8080` (or `https://api.bnxmail.com`)
- **Default Authentication:** Bearer JWT Token
  ```http
  Authorization: Bearer <jwt_token>
  ```
- **Content Type:** `application/json` (except file uploads which use `multipart/form-data`)

# 1. Storage APIs

Handles real-time mail server quota, mailbox storage consumption, and account plan limits.

---

### 1.1 Get Live Mail Storage Quota
Fetches real-time mailbox quota from Dovecot / IMAP.

- **Method:** `GET`
- **Route:** `/api/mail/storage-quota`
- **Headers:**
  ```http
  Authorization: Bearer <token>
  ```

#### Response (`200 OK`)
```json
{
  "success": true,
  "message": "Storage quota fetched successfully",
  "data": {
    "email": "user@bnxmail.com",
    "storageLimit": 5368709120,
    "storageUsed": 268435456,
    "storagePercentage": 5.0
  },
  "error": null
}
```

#### Field Specifications
| Field | Type | Description |
| :--- | :--- | :--- |
| `email` | `String` | Email address of the authenticated mailbox |
| `storageLimit` | `Long` | Maximum storage allocated on mail server in **Bytes** (`5368709120` = 5 GB) |
| `storageUsed` | `Long` | Consumed storage in **Bytes** (`268435456` = 256 MB) |
| `storagePercentage` | `Double` | Utilization percentage |

---

### 1.2 Storage Unit Reference
| Unit | Size in Bytes |
| :--- | :--- |
| **1 GB** | `1073741824` |
| **5 GB** *(Default Server Quota)* | `5368709120` |
| **15 GB** *(Default User Plan Limit)* | `16106127360` |
| **30 GB** | `32212254720` |

# 3. Mail Backup & Data Vault

Secure persistent storage for email backups, exports, archives, and encrypted attachments.

---

### 3.1 Upload / Store Backup in Vault
- **Method:** `POST`
- **Route:** `/api/vault/upload`
- **Headers:**
  ```http
  Authorization: Bearer <token>
  Content-Type: multipart/form-data
  ```

#### Form Data Parameters
| Field | Type | Description |
| :--- | :--- | :--- |
| `file` | `Binary File` | Backup file (`.zip`, `.eml`, `.mbox`, `.pdf`, etc.) |

#### Response (`200 OK`)
```json
{
  "message": "File uploaded successfully",
  "id": 104,
  "filename": "mail_backup_2026.zip"
}
```

---

### 3.2 List All Backed-Up Files
- **Method:** `GET`
- **Route:** `/api/vault`
- **Headers:** `Authorization: Bearer <token>`

#### Response (`200 OK`)
```json
[
  {
    "id": 104,
    "filename": "mail_backup_2026.zip",
    "contentType": "application/zip",
    "size": 48291040,
    "createdAt": "2026-09-29T16:40:00"
  },
  {
    "id": 101,
    "filename": "contacts_export.csv",
    "contentType": "text/csv",
    "size": 15420,
    "createdAt": "2026-09-15T11:20:00"
  }
]
```

---

### 3.3 Download Backup File
- **Method:** `GET`
- **Route:** `/api/vault/{id}/download`
- **Headers:** `Authorization: Bearer <token>`
- **Response:** Raw binary file stream

---

### 3.4 Delete Backup
- **Method:** `DELETE`
- **Route:** `/api/vault/{id}`
- **Headers:** `Authorization: Bearer <token>`

#### Response (`200 OK`)
```json
{
  "message": "File deleted successfully"
}
```

### 4.3 Language Preferences
- **Get:** `GET /api/settings/language`
- **Update:** `PUT /api/settings/language`
- **Supported Languages:** `en`, `ta`, `hi`, `te`, `ml`, `kn`
- **Request Body:**
  ```json
  {
    "language": "ta"
  }
  ```

---

### 4.4 Composing & Smart AI Preferences
- **Get:** `GET /api/settings/composing`
- **Update:** `PUT /api/settings/composing`
- **Request Body:**
  ```json
  {
    "spellingCheckEnabled": true,
    "grammarCheckEnabled": true,
    "autoCorrectEnabled": false,
    "smartComposeEnabled": true
  }
  ```

---

### 4.5 Typography & Text Style
- **Get:** `GET /api/settings/text-style`
- **Update:** `PUT /api/settings/text-style`
- **Supported Fonts:** `Arial`, `Calibri`, `Times New Roman`, `Georgia`, `Verdana`, `Courier New`, `Tahoma`, `Trebuchet MS`
- **Supported Sizes:** `Small`, `Normal`, `Large`, `Extra Large`
- **Request Body:**
  ```json
  {
    "fontFamily": "Georgia",
    "fontSize": "Large",
    "textColor": "#1E293B"
  }
  ```

---

### 4.6 Wallpaper & Theme Customization
- **Get:** `GET /api/settings/wallpaper`
- **Update:** `PUT /api/settings/wallpaper` (`{"wallpaper": "aurora_dark"}`)
- **Reset:** `POST` or `PUT` `/api/settings/wallpaper/reset`

---

### 4.7 Signatures
- **List:** `GET /api/signatures`
- **Create:** `POST /api/signatures`
  ```json
  {
    "name": "Work Signature",
    "content": "<p>Best regards,<br><b>Ashwin Kumar</b></p>",
    "isDefault": true
  }
  ```
- **Update:** `PUT /api/signatures/{id}`
- **Delete:** `DELETE /api/signatures/{id}`
- **Set Default:** `PATCH /api/signatures/{id}/default`

---

### 4.8 Two-Factor Authentication (2FA)
- **Setup (Generate Secret & QR):** `POST /api/users/2fa/setup`
- **Verify & Enable:** `POST /api/users/2fa/verify`
  ```json
  {
    "code": "492817"
  }
  ```
